# ocvim

Opencode with vim mode for the prompt input.

## Install

```bash
npm i -g opencode-vim
```

Then run:

```bash
ocvim
```


## Supported motions

`h` `j` `k` `l` `w` `b` `e` `W` `B` `E` `0` `^` `$` `gg` `G`
`i` `I` `a` `A` `o` `O` `x` `dd` `dw` `cc` `cw` `S`
`Ctrl+e` `Ctrl+y` `Ctrl+d` `Ctrl+u` `Ctrl+f` `Ctrl+b`

Syncs with upstream opencode automatically.
